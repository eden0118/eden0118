# Profile artwork

The README follows the terminal-banner, introduction and signals
layout of [emmi-lili](https://github.com/emmi-lili). Graphics are original and use
Eden's existing character and profile information.

The current layout is generated by `scripts/profile_layout.py`: an ASCII-led
introduction, three concise planning steps and a combined perspective diagram.
All panels have light/dark and phone/intermediate/desktop versions. The README
uses native `picture` source selection at 440px and 899px, so the same layout
works on GitHub. The intermediate layout keeps a horizontal hero and diagrams,
with three tool columns; the phone layout stacks them and uses two tool columns.
The intermediate version prevents the previous 600/601px
transition from shrinking three-column body text to about 10px.
See [the visual direction](../design-system/profile.md) for layout and palette.

The real ASCII portrait is generated from `assets/design.png` at 120 columns
and 76 rows by `scripts/terminal_art.py`. Each 10-second cycle pauses for 0.5
seconds, types for 3.5 seconds and holds the complete portrait for 6 seconds.
The animation uses embedded CSS with a cursor and no external services.
Reduced motion selects a complete static SVG through README's `picture`;
the animated SVG also includes its own reduced-motion fallback.

## Update profile data

The `Tools I work with` panel presents icons and names as a supporting tool
list, in two columns on phones and three on intermediate/desktop widths. It
omits capability labels and purpose captions. Individual badge sources
are local `assets/badge-*.svg` files from Shields.io, with AWS and Adobe marks
from `assets/icons/`. The panel lists draw.io, Figma, Mermaid, AWS, Rhino and Adobe Creative Cloud. They identify
tools and methods, not certifications or proficiency scores. Their backing
color is normalized to fit the profile palette. Artwork generation
preserves the source badges; order and layout live in `profile_layout.py`.

Icon sources: AWS wordmark from Devicon 2.17.0 (MIT; license included in
`assets/icons/DEVICON-LICENSE`), Adobe wordmark from
`https://www.adobe.com/federal/assets/svgs/adobe-logo.svg`, Rhino from the
Shields.io `rhinoceros` logo. Original mark proportions and colors are retained.

### 修改 Banner 文字

文字來源是 `assets/profile.json`，不需要直接編輯 `banner-light.svg` 或
`banner-dark.svg`。兩版 SVG 都由同一份資料產生：

| 欄位 | 顯示內容 |
| --- | --- |
| `subject` | 姓名 |
| `role` | 職稱 |
| `handle` | 帳號 |
| `intro` | 第一筆用於圖片說明，其餘自介自動換行顯示於姓名與職稱下方 |
| `strengths` | 舊版資料保留，已不顯示於 Banner |
| `tools` | 工具清單與順序，`key` 對應圖示檔名、`name` 是顯示名稱；工具區高度隨數量自動調整 |
| `experience` | 三個規劃步驟，`name` 是短標題、`description` 是自動換行的說明；`labels` 是保留的舊版資料，目前不顯示 |

修改後，執行下方「Regenerate and validate」的指令，同步更新深淺兩版。
自介與規劃步驟的內文會自動換行，但圖卡高度固定，請維持接近原本的
長度，並用 `preview.html` 檢查桌面及手機版是否超出面板。
SVG 是產生後的靜態圖片，不會在開啟時自動讀取 JSON；只改 JSON 還不會更新圖片。
README 的圖片替代文字（`alt`）另存於 `README.md`，內容變動時也請同步調整。

Edit `assets/profile.json` to change the banner fields and chart data. Edit the
prose in `README.md` separately. `preview.html` is generated directly from README
using a CommonMark parser, including its embedded HTML. Do not edit its content
separately. Run `python scripts/preview.py` after changing README; run
`python scripts/preview.py --check` to verify it is current. Preview styles live
in `scripts/preview-template.html`. Full artwork generation also updates preview.

GitHub statistics and language counts are a public-data snapshot as of the date
in `profile.json`; they are not automatically refreshed. `source` and
`repos_source` record the public API endpoints used. Language counts in the saved snapshot are no longer displayed.
The perspective panel combines the design roots (form, material and space) with
a map of shared planning decisions (needs, priorities and feasibility). The old
standalone roots and signals assets remain as unused experiments.

## Regenerate and validate

```sh
python3 -m venv /tmp/eden-profile-venv
/tmp/eden-profile-venv/bin/pip install -r scripts/requirements.txt
/tmp/eden-profile-venv/bin/python scripts/profile_art.py
/tmp/eden-profile-venv/bin/python scripts/check_art.py
```

Generation is deterministic and works offline from the stored profile data.
`profile_art.py` generates thirty referenced panel assets (including static and
three layout variants), optional statistics,
and six previous graphic experiments. The earlier language radar files are
also retained. Optional assets are not referenced by the README. The validation workflow checks local references,
size budgets, SVG descriptions, unique identifiers and absence of external embeds
or scripts. It also checks the ASCII portrait dimensions and character set.
It fails when preview differs from the generated README output, catching both
text differences and section-order differences before generation runs in CI.
